IBM Cloud Lite Services

JalDrishti-AI integrates four IBM Cloud Lite services as required by the problem statement

🤖
IBM watsonx.ai
Granite 4 H Small LLM powers the AI chatbot and generates state/national policy insights via the REST API.
GET /api/watsonx/national-insight
POST /api/watsonx/state-insight
POST /api/watsonx/chat
⚙️
IBM Watson ML
GradientBoostingRegressor is trained locally and deployed to Watson ML for remote scoring predictions.
POST /api/watson-predict
🗄️
IBM Cloud Object Storage
The nss78_21.xlsx dataset is uploaded to an IBM COS Lite bucket for persistent cloud storage and retrieval.
POST /api/cos/upload
🗃️
IBM Db2 on Cloud
MIS 78th Round records are stored in an IBM Db2 Lite instance for relational queries and reporting.
services/db2_service.py
